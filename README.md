# 💱 Currency Converter

This is a simple and lightweight currency converter web app built using HTML, CSS, and JavaScript.  
It lets you convert currencies in real time using live exchange rates through an API.

I built this project to practice working with APIs and improve my JavaScript skills.

---

## ✨ What it does

- Convert between different currencies easily  
- Fetch real-time exchange rates using an API  
- Works on both mobile and desktop  
- Clean and simple user interface  
- Fast and easy to use  

---

## 🛠️ Built With

- HTML  
- CSS  
- JavaScript (Vanilla JS)  
- Currency Exchange API
